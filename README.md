# 末日黎明：喪屍浩劫

壓抑寫實、心理驚悚向的殭屍末日生存文字冒險遊戲。以 AI（Google Gemini）即時生成劇情與動態選項，透過手機瀏覽器即可全螢幕點選遊玩，無需下載安裝任何 App。

## 專案簡介

本遊戲原型為一組 AI 對話式文字冒險 Gem 規則，現改造為可視化網頁版本（PWA），保留原有的核心設計：

- 時間隨每次行動推進，NPC 具備自主行為與疲勞機制
- 體力／疲勇度數值系統，歸零時強制觸發劇情轉折
- 漸進式異能覺醒：由極端情緒或關鍵抉擇觸發，非開局預設
- 病毒起源真相與五大勢力世界觀，採漸進式碎片化揭露
- 防重複回合協議，杜絕場景與選項套用固定模板

## 檔案結構

| 檔案 | 功用 |
| --- | --- |
| `index.html` | 遊戲畫面骨架：狀態欄、劇情區、動態按鈕面板、設定選單 |
| `style.css` | 末日壓抑風格視覺樣式（鐵灰底 + 暗紅警示配色） |
| `app.js` | 核心引擎：API 串接、狀態機、存檔匯出/匯入、畫面渲染 |
| `config.js` | 個人化設定：模型名稱、初始體力、Notion 同步參數 |
| `manifest.json` | PWA 設定：App 名稱、圖示、主題色、全螢幕模式 |
| `sw.js` | Service Worker：離線快取靜態資源 |
| `knowledge/virus_lore.txt` | 世界觀密檔：病毒起源真相、五大勢力設定 |

## 使用方式

1. 用手機瀏覽器打開部署後的網址。
2. 貼上你的 [Google AI Studio](https://aistudio.google.com/) 免費 API 金鑰（僅存於本機瀏覽器，不會上傳任何伺服器）。
3. 點擊「進入末日」開始遊戲，或用「匯入存檔」讀取先前的進度。
4. 點選動態生成的行動按鈕，或使用「自訂行動」輸入任意指令。
5. 瀏覽器選單選擇「加入主畫面」，可將遊戲變成手機桌面上的全螢幕圖示。

## 技術細節

- **AI 模型**：Gemini 2.5 Flash-Lite（免費層額度最充足，速度最快）
- **輸出格式**：強制 JSON 結構化輸出（`narrative` / `status_update` / `options`）
- **存檔機制**：`localStorage` 自動存檔 + 手動匯出/匯入 JSON 備份
- **部署平台**：Vercel（純靜態網頁，無需建置工具）
